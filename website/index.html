How it works

Three steps to deep focus

Set it once, then forget it. Monitry runs quietly in your menu bar and only interrupts when it matters.

01

Tell it your task

Type what you're working on. That's all the context Monitry needs.

02

AI watches your screen

Claude takes a screenshot every few seconds and decides if you're on track — no keystroke logging, no invasive monitoring.

03

Get called back in

When you drift, Monitry interrupts you with a firm reminder and makes you type a full sentence to dismiss it.

Features

Built to actually keep you honest

👁

Vision-based detection

No browser extension, no app integrations. Claude reads your screen exactly as you see it.

⌨️

Typing challenge dismissal

Can't click away from the warning. You have to type a full sentence to get back in.

🧠

Session memory

Monitry builds notes across checks so it understands your session context, not just the last screenshot.

📈

Adaptive intervals

Checks slow down when you're in flow, snap back to fast when you go off task.

🔒

Private by design

Screenshots go directly to Claude's API and are never stored. No keylogging.

💸

Pennies per hour

Runs on Claude Haiku for as little as $0.09/hr in API costs. Bring your own key.
